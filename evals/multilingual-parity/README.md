# portal

A bilingual demo. Languages deliberately REORDER their sections to prove parity
must not depend on heading position.

<!-- makewiki:section=usage -->

## Usage

[[id:usage.code]]
```bash
portal start --config config.yaml
```

## Run

[[id:run.code]]
```bash
portal serve
```

<!-- makewiki:section=config -->

## Configuration

Set `PORT` and `HOST` in `config.yaml`.

[[id:config.sample]]
```yaml
PORT: 8080
HOST: 0.0.0.0
```
