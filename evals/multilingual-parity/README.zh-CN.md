# portal

双语演示。两种语言刻意调整了章节顺序，以证明 parity 不依赖标题位置。

<!-- makewiki:section=config -->

## 配置

在 `config.yaml` 中设置 `PORT` 和 `HOST`。

[[id:config.sample]]
```yaml
PORT: 8080
HOST: 0.0.0.0
```

<!-- makewiki:section=usage -->

## 使用

[[id:usage.code]]
```bash
portal start --config config.yaml
```

## 运行

[[id:run.code]]
```bash
portal serve
```
